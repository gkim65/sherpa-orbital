## 3  Technical Decisions

**Physical units throughout.** CLAUDE.md mandates km/km/s/s; avoids implicit normalisation bugs. A `cr3bp_to_nondim` / `nondim_to_cr3bp` utility converts to/from the non-dimensional form used in CR3BP literature so initial conditions from papers can be directly imported.

**Rotating frame origin = Saturn–Enceladus barycentre.** Saturn at `x = −μ·L*`, Enceladus at `x = (1−μ)·L*`. This is the standard CR3BP convention. `X_SATURN` and `X_ENCELADUS` are module-level constants in `cr3bp.py` rather than computed inline, to avoid recomputation and enable import by other modules.

**Event detection via `ṙ_enc` sign change.** Apoapsis/periapsis detected by `d/dt(r_enc) = 0` with directional crossing (scipy `direction` flag). The altitude event (`make_altitude_event`) only detects descending crossings (direction = −1), matching Strategy 3's maneuver trigger from §B.2.3.

**J2 in rotating frame.** The Enceladus J2 perturbation is applied directly in the rotating frame. This is valid because: (1) the J2 symmetry axis (Enceladus spin pole) is approximately aligned with the orbit normal, i.e., z-axis of the rotating frame; (2) J2 is much smaller than the monopole term (J2 ≈ 5×10⁻³), so tidal coupling of the oblateness is negligible at these altitudes.

**Test structure mirrors src/.** One test file per source module, in matching subfolders under `tests/`. This is standard Python practice and keeps test discovery unambiguous as the codebase grows.

## 4  Physics / Math Notes

**Jacobi constant conservation:** Over 30 days of CR3BP propagation, the Jacobi constant drifts by < 10⁻⁸ relatively, confirming RK45 with rtol=1e-10/atol=1e-12 is sufficient.

**J2 divergence:** After 30 days, position error between CR3BP and CR3BP+J2 is **12.84 km** — well above the 1 km threshold used in the MacKenzie stationkeeping bounds. This confirms J2 is a physically meaningful perturbation and motivates the two-layer model architecture.

**Libration points (physical units):**
- L1: x_rel to Enceladus = −947.7 km (between Saturn and Enceladus, ~950 km from Enc)
- L2: x_rel to Enceladus = +950.2 km (beyond Enceladus, ~950 km from Enc)

These are symmetric to within ~2 km, as expected for μ << 1.

**Approximate IC note:** The IC used for tests (`x_nd = 1−μ+0.0085, z_nd = 0.0006, vy_nd = −0.0180`) is NOT a closed halo orbit. It is a large outer orbit (periapsis ~1570 km altitude, apoapsis ~3263 km altitude), NOT the mission's 20–70 km periapsis halo. A **differential corrector** is needed to find the true period-3 halo ICs. This is the Session 2 priority.
